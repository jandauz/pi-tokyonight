# Pi Tokyo Night Theme

A color theme for the [Pi coding agent](https://github.com/earendil-works/pi) based on the Night variant of [Folke Lemaitre's Tokyo Night](https://github.com/folke/tokyonight.nvim).

## Install

```sh
pi install git:github.com/jandauz/pi-tokyonight-theme
```

Then select `tokyo-night` in Pi's `/settings`, or set it in `~/.pi/agent/settings.json`:

```json
{
  "theme": "tokyo-night"
}
```

## Update

```sh
pi update git:github.com/jandauz/pi-tokyonight-theme
```
